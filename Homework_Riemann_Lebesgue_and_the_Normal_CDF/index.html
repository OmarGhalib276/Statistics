Riemann, Lebesgue and the Normal CDF

An integral can be built by slicing the horizontal axis, as Riemann did, or the vertical axis, as Lebesgue did. This page runs both on the same functions, from smooth curves to ones that break Riemann's method, and compares accuracy, convergence and cost.

It then turns to the most important integral in statistics, the area under the bell curve: it has no elementary antiderivative, yet it must be computed constantly, from p-values to intrusion-detection thresholds.

∫ f dx ≈ Σ f(xi) Δx ∫ f dμ = ∫0∞ μ{f ≥ t} dt Φ(x) = 12 [1 + erf(x√2)]
PART 1 · THEORY

Two ways to build an integral

Riemann cuts the domain: split [a, b] into N pieces of width Δx = b − aN, pick a point ξi in each (left end or middle) and add the rectangles:

RN = Σi=0N−1 f(ξi) · Δx

Lebesgue cuts the range: split the values into B bands yj = ymin + jh, and weight each level by the measure μ of its preimage Ej = {x : yj ≤ f(x) < yj+1}:

LB = Σj=0B−1 yj · μ(Ej)

Both sums approximate the same area. Four numerical versions are compared: Riemann left and midpoint (N evaluations of f); Lebesgue with exact preimages, where μ{f ≥ t} is known in closed form or found by bisection; and Lebesgue sampled, which evaluates f at M = N points and estimates each measure by the fraction of points falling in the band (usable on a black-box f, at Riemann's cost).

PART 1 · PATHOLOGICAL CASES

Where the two views disagree

Dirichlet (1 on rationals, 0 on irrationals). Every interval holds both kinds of numbers, so every upper Darboux sum is 1 and every lower sum is 0: f is not Riemann-integrable, and a Riemann sum can be anything between 0 and 1 depending on the tags. For Lebesgue, the preimage of 1 is ℚ ∩ [0, 1], countable, hence of measure 0 (cover the k-th point with an interval of length ε/2k): the integral is 0. On a computer the Lebesgue view cannot even be sampled, because every floating-point number is rational.

Thomae (1/q at p/q in lowest terms, 0 at irrationals) is discontinuous only on ℚ, a null set, so it is Riemann-integrable with integral 0. On N equal pieces the upper Darboux sum is exact: on each piece the supremum is 1/qmin, the smallest denominator inside it; the lower sum is 0.

The upper sums fall to 0 (roughly like N−1/2 in this range), so Riemann's limit is 0. Lebesgue sees it immediately: {f ≥ t} only contains fractions with denominator at most 1/t, a finite set of measure 0. Here the theories agree, but Riemann needs a limit of partitions to get there.

PART 2 · DEFINITION

The standard normal CDF

Φ(x) = P(Z ≤ x) = 1√(2π) ∫−∞x e−t²/2 dt

By symmetry Φ(0) = 12 and Φ(−x) = 1 − Φ(x), so x ≥ 0 is enough. The substitution t = √2 s on the integral from 0 to x gives the error function:

erf(z) = 2√π ∫0z e−s² ds  ⟹  Φ(x) = 12 [ 1 + erf( x√2 ) ]
PART 2 · LIOUVILLE

Why no elementary formula exists

Elementary functions are those built from rational functions, exponentials and logarithms by finitely many sums, products, compositions and inverses. Liouville's theorem (in Rosenlicht's form): for rational f, g with g not constant, ∫ f eg dx is elementary if and only if there is a rational R with R′ + g′R = f, and then it equals R eg.

For the bell curve f = 1 and g = −x²/2, so we would need a rational R with R′ − xR = 1. A pole of order k of R gives a pole of order k + 1 in R′ that xR cannot cancel, so R is a polynomial; but a polynomial of degree d gives R′ − xR of degree d + 1 ≥ 1 (and R = 0 gives 0), never the constant 1. Hence ∫ e−x²/2 dx, and with it Φ and erf, is not elementary. This does not make Φ undefined: it is smooth and well defined, it just has no finite formula in elementary functions.

Naming the integral erf makes Φ(x) = ½[1 + erf(x/√2)] exact, and erf has a rich theory (odd, entire, erf′(z) = 2√π e−z², Taylor series valid everywhere). But a name is not a number: to know that Φ(1.5) = 0.93319… an algorithm must still produce the digits, via an integral, a series, a continued fraction or a tuned approximation. That is why numerical methods remain necessary.

PART 2 · METHODS

Five ways to compute Φ(x)

1 · Trapezoidal rule

Φ(x) = 12 + ∫0x φ(t) dt with N trapezoids. Error ∝ h². Cost N + 1 exponentials.

2 · Simpson's rule

The same integral with parabolic caps (weights 1, 4, 2, …, 4, 1). Error ∝ h⁴. Cost N + 1.

3 · Maclaurin series of erf

erf(z) = 2√π Σk≥0 (−1)k z2k+1k!(2k + 1),   z = x√2

Converges everywhere, but for large z the alternating terms cancel almost every digit. Cost K terms.

4 · Abramowitz–Stegun 7.1.26

erf(z) ≈ 1 − (a1t + … + a5t5) e−z², t = 11 + 0.3275911z. Error below 1.5·10−7: one exponential, but a hard ceiling.

5 · Hybrid: positive series + continued fraction

For x < 3 the series with all terms positive (no cancellation); for x ≥ 3 the tail directly from the Mills-ratio continued fraction, depth 150, then symmetry:

erf(z) = 2√π e−z² Σk≥0 2k z2k+11·3·5⋯(2k + 1)    1 − Φ(x) = φ(x)x + 1x + 2x + 3x + …

Computing a tail as 1 − Φ would subtract two nearly equal numbers and lose the quantity wanted; this is the idea behind library implementations.

CONCLUSIONS

What the experiments show

Part 1 · Riemann versus Lebesgue

  • Same value, different accuracy. For every Riemann-integrable function both constructions converge to the same number. Riemann gains from smoothness (order 1 left, order 2 midpoint); Lebesgue is limited by the level spacing (order 1 always).
  • Efficiency. Riemann needs N evaluations; Lebesgue needs the preimage measures, or sampling at Riemann's cost, which is the Monte Carlo idea behind E[X] = ∫ x dP.
  • Where they differ. Dirichlet is not Riemann-integrable but has Lebesgue integral 0; Thomae is integrable for both, yet only Lebesgue sees it at once.

Part 2 · The normal CDF

  • No elementary formula, but exact via erf. Liouville rules out an elementary antiderivative; erf gives an exact representation, yet evaluating it always needs an algorithm.
  • Accuracy against cost. Simpson beats the trapezoid rule (order 4 against 2); the alternating series loses digits as |x| grows; A&S gives about 7 digits in one exponential; the hybrid reaches double precision by changing method with the region.
  • Tails need relative accuracy. Computing the tail directly, not as 1 − Φ, is what keeps error rates and p-values correct.
